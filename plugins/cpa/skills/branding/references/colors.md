## Usage Notes for Executive Financial Deliverables

### Recommended chart series order (CPA / JHM exec audience)
1. Navy `#002d74` — primary series
2. Gold `#f3c300` — secondary series
3. Deep Teal `#007078` — tertiary series
4. Dark Olive `#ab8900` — quaternary series
5. Medium Gray `#9d958c` — comparison / benchmark series

### Performance / variance coding (colorblind-safe)
- **Favorable / on target**: Navy `#002d74` or Olive Green `#638c1c`
- **Unfavorable / below target**: Dark Warm Gray `#6e615d` or Dark Crimson `#7f2629`
- **Neutral / prior period**: Medium Gray `#9d958c`
- ❌ Never use Bright Red `#e1251b` and Bright Green `#3dae2b` together as a pair

### XLSX tab color coding
- Summary / output tabs: Navy `#002d74`
- Input / assumption tabs: Gold `#f3c300`
- Reference / lookup tabs: Medium Gray `#9d958c`
- Sensitivity / scenario tabs: Deep Teal `#007078`
